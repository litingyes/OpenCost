# Product

## Register

product

## Users

Solo developers who run local AI agents (Cursor, CLI agents, IDE copilots) and need to see where token spend actually goes. They open OpenCost at the desk for quick checks—often alongside an IDE or terminal—not for long reporting sessions.

## Product Purpose

OpenCost is a native desktop app that tracks and explains local agent token usage: which sessions, models, and workflows consume the most, and where waste or surprising patterns show up. Success means turning opaque token burn into actionable clarity in seconds, not exporting spreadsheets.

A marketing site may come later; the default design register is the product app.

## Brand Personality

Insightful, analytical, slightly opinionated. Voice is direct and specific—surfaces patterns and waste without alarmism. Feels like a precision dev tool (Linear-like density and motion) rather than a finance dashboard or novelty consumer app.

## Anti-references

- Crypto / fintech neon aesthetics (glow, purple gradients, trading-terminal drama)
- Generic SaaS dashboard slop (cream heroes, gradient metric cards, eyebrow kickers on every section)
- Enterprise bloat (corporate blue, alert fatigue, tables without narrative)

## Design Principles

1. **Show where tokens go** — breakdowns and attribution beat a single total; every screen should answer "spent on what?"
2. **Opinionated insight** — highlight anomalies, drift, and waste; the app should notice things the user might miss
3. **Glanceable at the desk** — optimized for solo dev context switches: open, understand, close
4. **Native desktop discipline** — keyboard-friendly, crisp hierarchy, motion with purpose (Linear as north star)
5. **Clarity over chrome** — analytical without becoming a dense enterprise console

## Accessibility & Inclusion

WCAG 2.1 AA: sufficient contrast for body and UI text, visible focus states, full keyboard navigation for core flows. Respect `prefers-reduced-motion` with non-animated fallbacks. Chart and data views should not rely on color alone to convey meaning.
